# Road to 4.0

A public-readable, personal-first training guide for developing a dependable 4.0 pickleball game.

The guide centers on a reusable two-week training cycle, a two-hour weekly ball-machine session, prioritized drill guides, monthly self and expert video review, measurable standards, and a tournament-pressure routine.

## Local preview

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static client build is written to `dist/client` and is compatible with GitHub Pages. Public Pages deployment is intentionally not configured until the local design is approved.
